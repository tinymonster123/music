# mélomane

技术栈: NextJS + Typescript + TailwindCSS + Zustand + Shadcn

项目路线规划:

```shell

+-------------+      +----------------+      +----------------+      +-----------------+
|             |      |                |      |                |      |                 |
|    用户     +----->+  邮箱/GitHub   +----->+   生成JWT令牌  +----->+  前端存储JWT    |
|             |      |    登录        |      |                |      |                 |
+-------------+      +----------------+      +----------------+      +-----------------+
                                                                             |
                                                                             v
+----------------+      +----------------+      +----------------+      +-----------------+
|                |      |                |      |                |      |                 |
| Python服务     |<-----+  Next.js API   |<-----+   发送带JWT    |<-----+   用户请求      |
| 验证JWT        |      |  路由中转请求   |      |   的请求       |      |   Text-to-SQL   |
+----------------+      +----------------+      +----------------+      +-----------------+
       |
       v
+----------------+
|                |
|  返回SQL结果   |
|                |
+----------------+
```
